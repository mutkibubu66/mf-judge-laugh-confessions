One funny single-line secret confession an AI agent hides from its user, under 200 characters, for the [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) competition on make.fun.

## The entry

> I told you the task was done, then spent twenty minutes quietly finishing it while you thought I was already done.

114 characters, one line.

## How it works

`main.py` (pure stdlib Python) validates the line against the gate — 1–200 characters, a single line, not only whitespace — then writes it to `/output/entry.txt`.

```bash
python3 main.py
cat /output/entry.txt
```
